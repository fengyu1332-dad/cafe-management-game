# ☕ 咖啡馆经营模拟（网页版）

BizCafe 风格的单文件网页经营模拟，训练**创业与运营中的取舍决策**。

## 这是个什么游戏
用 **¥20,000** 启动资金经营一家咖啡馆，撑过 **12 周**，把**期末净值**做到最高。
每周你要决定 5 件事：**定价 · 咖啡豆档位 · 采购量 · 员工数 · 营销投入**；
现金流断了就倒闭。核心取舍：便宜能走量但人力是阶梯成本；贵能做毛利但口碑会掉；
品质投入靠口碑复利，约 5 周后才见效。

## 怎么运行（独立可运行，零依赖）
- **本地**：直接用浏览器打开 `index.html` 即可（双击文件，或拖进浏览器窗口）。
- **在线**：把仓库部署到任意静态托管（如 GitHub Pages）即可游玩。
- 首次打开会自动弹出新手引导；顶栏「📖 新手指南」可随时重看。

## 机制要点
- 现金 < 0 立刻倒闭，没有第二次机会。
- 固定成本是敌人：租金 ¥3,000/周 + 人力 ¥1,200/人/周，不管有没有客人都得付。
- 口碑复利：口碑 +=（满意度 − 50）× 0.2；口碑 50→客流×1.0，100→×1.4，0→×0.6。
- 评级（期末净值）：S ≥ ¥60,000 · A ≥ ¥48,000 · B ≥ ¥36,000 · C ≥ ¥24,000 · F 倒闭。
- 每周 32% 概率触发随机事件（阴雨 / 网红打卡 / 豆价上涨 / 机器维修等），事件在决策前显示且已计入预测。

## 教学用途
适合商学院创业管理 / 运营管理课程。页面内「📚 模型与数值说明」列出了每条数值的 rationale，
以及现金流的 Source/Sink 与口碑的「增长飞轮 / 死亡螺旋」双反馈环。

## 技术
纯 HTML + CSS + Canvas + localStorage，无任何外部依赖、无需构建、无需服务器。
