📚 模型与数值说明（每条数字都有 rationale）

需求模型：需求 = 700 × 价格因子 × 豆档因子 × 口碑因子 × 营销因子 × 装修因子 × 事件因子

  • 基准客流 700 杯/周：参考价¥18、口碑50、精品豆、无营销时的周需求，约 100 杯/天（社区咖啡馆量级）。
  • 价格因子 = (18/价格)^1.5，钳制 0.25–2.2：现制饮品需求价格弹性经验值 1.2–1.8，取 1.5；钳制防止极端定价让模型崩坏。
  • 豆档 客流 0.92/1.00/1.08、满意度 −8/+2/+10：品质对客流影响小、对满意度影响大——品质是长期复利而非即时按钮。
  • 口碑因子 = 0.6 + 口碑/100×0.8：口碑50→1.0；100→1.4；0→0.6。
  • 营销因子 = 1 + 0.28×(1−e^(−mkt/1200))：递减收益，首 ¥1200 换约 +18% 客流，之后边际骤降，防止无脑砸钱。

成本结构：原料 ¥3/¥5/¥8 每杯（占售价 17%–44%）· 员工 ¥1,200/人/周，产能 300 杯/人（人力是阶梯成本，是核心取舍）· 租金 ¥3,000/周（固定成本，逼你做量）· 库存每周损耗 5%（惩罚过度采购）。

口碑更新：口碑 += (满意度−50)×0.2；满意度 = 50 + 豆档 + 性价比(±15) − 排队惩罚12。约 5 周才能把口碑从 50 推到 65。

经济系统 Source / Sink：

  • Source（现金流入）：营业收入、贷款（周转用）。
  • Sink（现金流出）：原料、人力、租金、营销、设备/装修投资、贷款利息、库存损耗。
  • 投资是必要的 Sink：现金囤积会躺赢，所以设备（产能+20%/人）与装修（口碑+8、客流+5%）既是增长手段，也是后期现金出口。
  • 两个反馈环：口碑↑→客流↑→收入↑（正循环）；排队/低质→满意度↓→口碑↓→客流↓（死亡螺旋）。

每周的 5 个决策
每个杠杆：它影响什么，它的代价是什么

💵 单杯定价 ¥8–40

客流因子 = (18 / 定价)^1.5，钳制 0.25–2.2。参考价 ¥18 → 因子 1.0。越贵客流越少，但单杯毛利越高。

🫘 咖啡豆档位 普通 ¥3 / 精品 ¥5 / 顶级 ¥8

客流 ×0.92 / 1.00 / 1.08，满意度 −8 / +2 / +10。品质对客流影响小、对满意度影响大——它是长期复利，不是即时按钮。

📦 采购量（杯份）

卖不掉的库存每周损耗 5%，还占用现金。建议值 = 上周需求 × 1.1 − 现有库存，别囤。

👥 员工数 1–5 人

产能 300 杯/人/周，¥1,200/人/周。人力是阶梯成本：配多了纯烧钱，配少了排队流失且满意度 −12。

📣 营销投入 ¥0–3,000

客流 ×(1 + 0.28 × (1 − e^(−m/1200)))。递减收益：首 ¥1,200 换约 +18% 客流，之后边际骤降。

每周还有 32% 概率触发随机事件（阴雨 / 网红打卡 / 豆价上涨 / 机器维修等）。事件在决策前就显示，且已计入客流预测——不会暗算你，但你要提前反应。

三个必踩的坑
以及三条验证过能活下来的路
坑 1 · 人手配太多。每人每周 ¥1,200 是刚性支出。客流喂不饱产能时，多雇的人就是纯烧钱，还会把你拖向死亡螺旋。
坑 2 · 定位撕裂。又想便宜走量又想高品质：低价压毛利，顶级豆抬成本，两头不讨好，口碑和现金一起掉。
坑 3 · 囤货。每周 5% 损耗，还占着现金——而现金为负直接倒闭。宁可少订 10%，也别多订 50%。
三条活下来的路（都是实测过的净值区间）：
· 精算最优：¥20 / 精品豆 / 2 人 / 0 营销 → 约 ¥62,000，S 档
· 均衡精品：¥18 / 精品豆 / 3 人 / ¥800 → 约 ¥56,000，A 档
· 平价走量：¥12 / 普通豆 / 5 人 / 0 营销 → 约 ¥35,000，B~C 档（必须喂饱产能）
心法：先定定位，再配产能，最后才谈营销。五个杠杆不是各自最优，是彼此成全。
